# AA Styling — Starter Site

A responsive one-page website ready for GitHub Pages. The publishable website is entirely inside `docs/`.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload this project.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select your default branch and the `/docs` folder, then save.

## Before launch

- Replace sample service names/prices, salon details, and schedule.
- Replace booking links in `docs/index.html` with Avery’s final salon/Square URLs.
- Create a Formspree form and replace `YOUR_FORM_ID` in `docs/index.html`.
- Connect the final domain in GitHub Pages settings.
- Confirm Avery has permission to use every image and testimonial published.

The form deliberately stays in preview mode until a real Formspree ID is added.
